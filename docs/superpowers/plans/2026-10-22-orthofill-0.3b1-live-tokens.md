# Orthofill 0.3 beta 1 — живой протокол и токены: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Протокол собирается сам по мере набора записи (Ctrl+Enter — подтвердить: буфер и журнал); принятые подсказки с известным пунктом становятся токенами — подсвеченными словами, которые разбираются как слова врача.

**Architecture:** Движок принимает токены записи как временные слова врача (`build_protocol(wb, raw, tokens)`). Контроллер различает «черновик» (`preview` — без журнала и буфера) и «подтверждение» (`generate`). Окно пересобирает черновик после паузы, хранит токены тегами поля записи, останавливает живое обновление после ручной правки протокола.

**Tech Stack:** Python 3.12, tkinter/ttk + sv-ttk, pytest.

**Spec:** `docs/superpowers/specs/2026-10-22-orthofill-0.3-smart-input-design.md` — «0.3 beta 1», «Ответы на проверку описания», «Анти-цели».

## Global Constraints

- Черновик: пересборка через 300 мс паузы после правки записи; подчёркивание непонятых — через 800 мс; набор отменяет отложенную пересборку (`after_cancel`). Черновик **не** копируется и **не** пишется в журнал/диагностику.
- Ctrl+Enter / «Сформировать и копировать» — подтверждение: протокол **как он в поле** (с ручными правками) — в буфер; запись — в журнал; событие `generate` (+ `tokens`) — в диагностику.
- В буфер — только Ctrl+Enter / «Копировать» (и «Добавить пункт» больше не копирует).
- Ручная правка протокола → живое обновление выключено, полоска «Запись изменилась — обновить протокол? [Обновить] [Оставить]»; «Оставить» прячет кнопки, не всплывает заново; включается после «Обновить» или Ctrl+Enter.
- Токен — только у подсказки с кодом (`Hint.code`): слово словаря врача или слово ровно одного пункта. Разбор токена — путь словаря (отрицание, «названный эластик главнее»).
- Версия `0.3.0b1` / «0.3 beta 1»; `CHANGELOG.md` — «0.3 beta 1».

## Review Focus

1. Быстрый набор 40 символов подряд → ни одной пересборки до паузы; после паузы — одна (Task 3 `test_debounce_one_rebuild`).
2. Протокол поправлен руками, врач дописывает запись → правка не стёрта (Task 3 `test_hand_edit_freezes_live`).
3. Ctrl+Enter после ручной правки → в буфер ушёл протокол с правкой (Task 3 `test_confirm_copies_edited`).
4. Набор внутри токена / удаление части → привязка снята (Task 4 `test_typing_inside_token_unbinds`).
5. Черновик ничего не пишет в журнал (Task 2 `test_preview_writes_nothing`).

```python
def test_token_selects_item_for_this_note_only(wb):
    p = build_protocol(wb, 'лигатурная, квакозябра', tokens=[('квакозябра', '4g3')])
```

### Task 2: Контроллер — черновик и подтверждение

**Files:** Modify `orthofill/controller.py`. Test: `tests/test_tokens.py`.

**Interfaces:**
- Consumes: Task 1.
- Produces:
  - `Controller.preview(raw, tokens=()) -> GenerateResult` — `build_protocol` без журнала, буфера, диагностики, счётчиков словаря; `copied=False`; статус «черновик — Ctrl+Enter подтвердить».
  - `Controller.generate(raw, copy=True, tokens=(), text: str | None = None)` — подтверждение: как сейчас, плюс `tokens` в событии `generate`; если `text` задан (протокол поправлен руками) — в буфер и `log_copy` идёт он.
  - `Controller.find_unknown(raw=None, tokens=())` — по переданной записи (черновик), токены не подчёркиваются.
  - `Controller.bind_word(word, code) -> str` — для «Добавить пункт» к слову: `learn` + статус «Слово «…» → <пункт>; протокол обновлён» (без вставки строки и копирования).
  - `add_item(...)` — без `self.copy(new)`; статус «… добавлено в протокол — Ctrl+Enter подтвердить».

- [ ] **Step 1: tests**

```python
def test_preview_writes_nothing(ctl, order_xlsx, clip):
    ctl.import_xlsx(order_xlsx)
    n = ctl.journal._db.execute('SELECT COUNT(*) FROM entries').fetchone()[0]
    r = ctl.preview('лигатурная, перепел')
    assert r.text and not r.copied and not clip
    assert ctl.journal._db.execute('SELECT COUNT(*) FROM entries').fetchone()[0] == n

def test_confirm_with_edited_text(ctl, order_xlsx, clip):
    ctl.import_xlsx(order_xlsx)
    ctl.generate('лигатурная', text='мой протокол')
    assert clip[-1] == 'мой протокол'

def test_add_item_does_not_copy(ctl, order_xlsx, clip):
    ctl.import_xlsx(order_xlsx); ctl.generate('лигатурная'); clip.clear()
    ctl.add_item(ctl.last_protocol.text, '4g3')
    assert not clip

def test_tokens_in_diagnostics(ctl, order_xlsx):
    ctl.import_xlsx(order_xlsx); ctl.set_diagnostics(True)
    ctl.generate('лигатурная, квакозябра', tokens=[('квакозябра', '4g3')])
    ev = [e for e in _events(ctl) if e['event'] == 'generate'][-1]
    assert ev['tokens'] == [['квакозябра', '4g3']] and '4g3' in [c for c, _ in ev['lines']]
```
