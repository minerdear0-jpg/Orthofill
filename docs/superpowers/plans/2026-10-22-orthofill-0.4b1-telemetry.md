# Orthofill 0.4 beta 1 — телеметрия: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Программа шлёт события диагностики и поведения врача (без ФИО) на сервер заказчика в реальном времени, не задерживая ввод и ничего не теряя без сети; приёмник на Debian хранит их и показывает живую страницу: лента, использование функций по дням, скорость.

**Architecture:** Клиент — без новых зависимостей: `scrub.py` (вырезание ФИО), `telemetry.py` (настройки `telemetry.json`, файл-очередь, фоновый отправитель на `urllib` + `ssl` с единственным доверенным сертификатом), `behavior.py` (счётчики записи без Tk). `DiagLog` отдаёт каждое событие и в телеметрию; события поведения идут через `Controller.track`. Приёмник — `server/` на `aiohttp` + SQLite WAL, свои тесты и зависимости (сборка программы их не тянет); установка — `server/install.sh`.

**Tech Stack:** Python 3.12, tkinter, sqlite3, urllib/ssl/threading (клиент), aiohttp (сервер), pytest.

**Spec:** `docs/superpowers/specs/2026-10-22-orthofill-0.4-telemetry-design.md` — «Программа», «Вырезание ФИО», «Приёмник», «Защита», «Анти-цели».

## Global Constraints

- Отправка только при **включённой «Диагностике»** и найденном `telemetry.json`; иначе ни одного сетевого соединения.
- `telemetry.json`: `{"url": "https://IP:порт", "key": "...", "cert": "-----BEGIN CERTIFICATE-----...", "doctor": ""}`; поиск: рядом с exe → `data_dir()` → встроенный (`_MEIPASS`). В `.gitignore`.
- TLS: `ssl.create_default_context(cadata=cert)`, `check_hostname=True` (IP в SAN); системные центры **не** загружаются.
- Поток окна никогда не ждёт сеть и диск очереди дольше записи одной строки: `Telemetry.put` — `queue.Queue.put_nowait`; запись в файл-очередь и отправка — в фоновом потоке (daemon).
- Файл-очередь: `telemetry/spool-*.jsonl` рядом с базой; лимит 50 МБ — старшие файлы переносятся в `telemetry/overflow/` (не удаляются молча), счётчик `overflowed`.
- Отправка: пачка ≤ 500 событий, раз в 5 с или при 100 в очереди; таймаут 10 с; ошибка → пауза 5 с ×2 до 5 мин; 429 — пауза из `Retry-After`.
- ФИО вырезаются **до** файла-очереди (клиент) и **до** записи в базу (сервер); замена `‹ФИО›`; локальная `diagnostics/` — как раньше, с исходным текстом.
- Ответ сервера на `POST /v1/events` — только `{"accepted": N, "duplicates": M}`; клиент из ответа берёт лишь код статуса.
- Сервер: тело ≤ 1 МБ, ≤ 500 событий, 600 запросов/мин на IP, неверный ключ/пароль — 10 за 10 мин → блок IP на 1 ч; хранение 180 дней.
- Версия `0.4.0b1` / «0.4 beta 1»; `CHANGELOG.md` «0.4 beta 1».

## Review Focus

1. Сервер «висит» (принимает соединение и молчит) — набор и Ctrl+Enter не тормозят, программа закрывается без ожидания (Task 2 `test_hung_server_does_not_block`, `test_close_does_not_wait`).
2. Программа закрыта посреди отправки, потом запущена — события дошли, повторов на сервере нет (Task 2 `test_spool_survives_restart`, Task 5 `test_duplicate_ids_ignored`).
3. Сертификат сервера подменён (другой самоподписанный на том же IP) — ничего не отправлено, в «О программе» «сертификат не совпадает» (Task 2 `test_foreign_cert_refused`).
4. «Иванова Мария Петровна, брекеты» и «пац. Петров И.И.» — в файл-очереди и в базе сервера `‹ФИО›`; «класс по Энглу» не тронут (Task 1, Task 5 `test_server_scrubs_again`).
5. Диагностика выключена — ни одного сокета, очередь не пишется (Task 3 `test_off_means_no_network`).

**Interfaces:**
- Consumes: Task 3 `Controller.track`.

  - `hint`: `action` `shown|accepted|ignored|erased`, `via` `tab|right|list|mouse`, `kind` (`doctor|history|item`), `pos`, `prefix_len` (`shown` — один раз на показ списка; `ignored` — список закрыт без выбора; `erased` — принятое слово стёрто ≤ 5 с);

  - `protocol_edit`: `before_confirm` (строк), `live_bar` `shown|update|keep`;
