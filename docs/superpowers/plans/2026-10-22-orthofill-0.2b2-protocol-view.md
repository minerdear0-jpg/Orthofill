# Orthofill 0.2 beta 2 — новый вид протокола. План реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** протокол читается глазами: группа и вариант — одной строкой без повторов, разделы жирные с отступом, строки, где программа сама что-то предположила, помечены на полях; сверка эталонов идёт по кодам, старые эталоны переводятся в новый вид сами.

**Architecture:** `Protocol.lines` остаётся списком «код → текст пункта» (по строке на каждый выбранный пункт: раздел, группа, вариант, отдельный пункт) — это модель. Новое `Protocol.rows` — строки вывода (склейка в `render.py`), из них собирается `Protocol.text` для окна и буфера. Движок помечает группы, по которым он предполагал (`ctx.flag`), и эти пометки переходят в `Row.check`. Эталоны сравниваются по кодам; старые эталоны нормализуются при чтении (`normalize_references`), идемпотентно.

**Tech Stack:** Python 3.12, tkinter (теги Text: `font`, `spacing1`, `lmargin1/lmargin2/lmargincolor`), pytest, uv.

**Spec:** `docs/superpowers/specs/2026-10-21-orthofill-0.2-design.md` — этап 2 («Склейка», «Сверка эталонов», «Метка «проверьте»», «Буфер») и перенесённый из этапа 1 перевод старых эталонов.

## Global Constraints

- Версия: `__version__ = "0.2.0b2"`, `VERSION_LABEL = "0.2 beta 2"`.
- В буфере — чистый текст: без пустых строк, без меток и служебных символов.
- Строки по умолчанию **не** помечаются «проверьте»; список «по умолчанию» под протоколом остаётся.
- Группа + вариант — одна строка; повтор текста группы в начале варианта убирается.
- Сверка эталонов — по набору и порядку кодов; строки эталона без кода не участвуют.
- Режимы вывода `join/separate/child_only` удаляются.
- Разбор записи не меняется: `tests/cases/*.json` и выбор пунктов (`Protocol.lines` по кодам) проходят как раньше.
- Коммиты заканчиваются строкой `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

### Task 1: Склейка строк (`render.py`)

**Files:**
- Create: `orthofill/render.py`
- Test: `tests/test_render.py`

**Interfaces:**
- Produces:
  - `@dataclass Row: text: str; codes: tuple[str, ...]; section: bool = False; check: list[str] = field(default_factory=list)`
  - `join_group(group_text: str, variant_text: str) -> str` — правила:
    1. слова сравниваются по `norm` без знаков препинания по краям слова;
    2. если вариант начинается со всех слов группы (без завершающего «:») → только вариант (как есть);
    3. иначе, если последние k слов группы совпадают с первыми k словами варианта (k максимальное ≥ 1) → группа + вариант без этих k слов;
    4. иначе вариант с заглавной буквы → `«группа: вариант»`; со строчной → `«группа вариант»`;
    5. в случаях 3–4 в конце ставится «.», если строка не кончается на `. : ! ?`; лишние пробелы схлопываются.

### Task 2: Движок — строки вывода, пометки «проверьте», без режимов вывода

**Files:**
- Modify: `orthofill/engine.py`, `orthofill/render.py` (`render_rows`)
- Test: `tests/test_engine.py` (заменить `test_join_mode_from_reference`), `tests/test_render.py`

**Interfaces:**
- Consumes: `Row`, `join_group` (Task 1).
- Produces:
  - `Protocol(lines, warnings, defaults, rows: list[Row])`; `Protocol.text` = строки `rows` через `\n`.
  - `Protocol.lines` — по строке на **каждый** выбранный пункт: `(раздел)`, `(группа)`, `(вариант)`…, `(отдельный пункт)`; группа выводится всегда перед своими вариантами (в т.ч. для групп с текстом на «:»); группа без выбранного варианта (`[]`) — только `(группа)`.
  - `render.render_rows(wb: Workbook, lines: list[tuple[str, str]], flags: dict[str, list[str]]) -> list[Row]` — раздел → `Row(section=True)`; группа + каждый её вариант → `Row(join_group(...), (группа, вариант))`; группа без вариантов → `Row(группа.text, (группа,))`; отдельный пункт/orphan → как есть. `check` строки = `flags` по любому из её кодов.
  - `_Ctx.flag(code: str, reason: str)` — пометка группы. Ставится:
    - `relation`: выбран вариант, а в записи нет «справа»/«слева» → «сторона не указана — проставлены обе»;
    - `wire`: выбран вариант при `f['wire_no_arch']` → «челюсть не указана — дуга на обеих»;
    - `visit`: выбран ближайший срок → «срока N нед нет — выбран ближайший»;
    - новая группа (`method == 'words'`): вариант выбран по словам → «выбрано по словам записи — проверьте»; вариант не распознан (`[]`) → текст того же предупреждения;
    - `binding`/`adjust`/`complaint`: при их предупреждениях — тем же текстом, на группу/раздел.
  - Удалить `_render_modes`, `_render`.

    - строки без кода и разделы — как есть.
  - Вызывается в конце `load_workbook_file` и в `PresetStore.load`.
  - `CaseResult` + поле `own_lines: int` (строк без кода). `check_references` сравнивает `[код для строк эталона с кодом]` с `[код для p.lines]`; `missing/extra` — `(код, текст пункта)`; `ok` — списки кодов равны.
  - `lines_for_reference(wb, generated, final_text)` — строка окна совпала с `Row.text` (без учёта пробелов) → `(код, текст пункта)` для всех `row.codes`; совпала с текстом пункта → его код; совпала с `join_group` любой пары группа+вариант пресета → оба кода; иначе `('', строка)`.
  - `Controller._refresh_status`: для эталонов с `own_lines` в details — `«эталон N: свои строки врача — K (не проверяются)»`.
