# 0.5 beta 8 — родитель, «начинается с», развилка веток — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tab в оболочке сужается по родителю, короткие значения «по памяти» находятся первым Tab, а значение из нескольких веток выбирается через развилку (сначала ветка, потом значение — как в fish).

**Architecture:** Всё решается в `shell._resolve` (без Tk): (1) точное имя узла = этот узел, поиск только внутри него; (2) `choices` — не конечные значения, а варианты на уровне развилки (`common` + 1 уровень), ветка с одним подходящим значением сразу показывается значением; (3) `Resolution.starts` — варианты, начинающиеся с набранного, их карусель ставит первыми. `shellbox` только показывает: у ветки « ›» и число подходящих значений, выбор ветки сохраняет недописанные слова.

**Tech Stack:** Python 3.12, tkinter, pytest (живой дисплей :0).

**Spec:** решения пользователя в разговоре 23.10.2026 + мокап `.superpowers/brainstorm/3813579-1792728266/content/parent-narrow-2.html` (вариант А выбран: «это правильно так делается в реальных оболочках»).

## Global Constraints

- Цифра родителя («4») — **не делаем** («цифра не требуется пока»).
- «Никогда не угадывать»: родитель — только при **точном** совпадении набранного с именем узла; остальные варианты не выбрасываются, а идут ниже.
- Ввёл родителя → видны все его значения и ветки (и значения прямо у родителя: 4a, 4h1, 4j).
- `осмо` + Tab → «Лечение: › осмотр.» (первый в карусели, Enter принимает).
- `014` есть в «верхней» и «нижней» — развилка: сначала ветка, потом значение.
- Версия `0.5.0b8` / «0.5 beta 8»; CHANGELOG и README — по-русски.
- Ветка `feature/0.5b8` от `feature/0.5b7` (b7 ещё не слит в main).

## ТРИЗ

- **Противоречие:** чем больше значений находит слово (поиск по любому слову любого уровня), тем легче вспомнить «по памяти» — и тем длиннее карусель (`niti` → 16, `осмо` → 5, нужное последним).
- **ИКР:** дерево пресета само сужает выбор; новых настроек и словарей нет.
- **Разрешение:**
  - *разделение во времени* — развилка: Tab дописывает общее, затем выбор ветки (2), затем значения (3) вместо 6 сразу;
  - *разделение по условию* — точное имя узла = родитель; неточное — как раньше;
  - *принцип местного качества* — у каждого варианта свой ранг: «начинается с» выше, «слово внутри текста» ниже.
- **Ресурсы:** уже есть `Resolution.common` (общая часть путей), `rest` (недописанные слова), статистика врача (`rank`), порядок файла.

## Review Focus

1. Набранное точно равно имени и раздела, и значения (одинаковые тексты в разных ветках: «на верхней челюсти.» в 4d1 и 4e1) — должны остаться все такие узлы, не первый попавшийся.
2. Ветка развилки с одним подходящим значением — показывается сразу значением (не лишний шаг).
3. Выбор ветки **мышью** и Enter — одинаково сохраняют недописанные слова («014»).
4. Частые варианты врача (`rank`) не должны выталкивать «начинается с» вниз: сначала «начинается с», внутри — частота, затем порядок файла.
5. Другая раскладка («kfxtybt» = «лечение») — точное имя работает и через неё.

### Task 2: развилка — варианты на уровне `common + 1`, число и «начинается с»

**Files:**
- Modify: `orthofill/shell.py` (`Resolution`, `_resolve`)
- Test: `tests/test_shell.py`

**Interfaces:**
- Consumes: Task 1.
- Produces: `Resolution.counts: dict[Path, int]` (сколько подходящих значений за вариантом), `Resolution.starts: set[Path]` (варианты, у которых текст значения — или любого подходящего значения за веткой — начинается с первого набранного слова). `choices` = для каждого подходящего значения `p[:len(common)+1]`, без повторов, в порядке файла; если за вариантом одно значение — вместо ветки сам путь значения.

- [ ] **Step 1: тесты**

```python
def test_fork_branches(wb):
    r = resolve(wb, (), '014', {})
    assert r.common == ('4',)
    assert r.choices == [('4', '4b'), ('4', '4c')]
    assert r.counts[('4', '4b')] == 3 and r.counts[('4', '4c')] == 3

def test_fork_inside_branch_gives_values(wb):
    r = resolve(wb, ('4', '4b'), '014', {})
    assert len(r.choices) == 3 and all(len(p) == 3 for p in r.choices)

def test_single_value_branch_collapses(wb):
    r = resolve(wb, (), 'осмо', {})
    assert ('4', '4a') in r.choices and ('3',) in r.choices
    assert r.counts[('3',)] == 3
    assert ('4', '4a') in r.starts and not any(p[0] == '1' for p in r.starts)

def test_unique_unchanged(wb):
    r = resolve(wb, (), 'перепел', {})
    assert r.leaves == [('4', '4f', '4f1')]
```
