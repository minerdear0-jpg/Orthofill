# Orthofill 0.3 beta 2 — привычки ввода (fish shell): Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Серым — привычный хвост фразы и следующая фраза из записей этого врача (по пресету); → / Tab — принять всё, Ctrl+→ — одно слово.

**Architecture:** `habits.py` без Tk: фразы прошлых записей пресета (по запятым и переводам строк) → частоты и пары «фраза → следующая фраза»; `continuation(text_before_cursor)` → хвост. Окно: тот же `HintBox` (серый хвост и клавиши) — в режиме «фраза»; список подсказок слов в этом режиме не показывается.

**Tech Stack:** Python 3.12, tkinter, sqlite3, pytest.

**Spec:** `docs/superpowers/specs/2026-10-22-orthofill-0.3-smart-input-design.md` — «0.3 beta 2», «Анти-цели».

## Global Constraints

- Источник — только записи этого пресета из журнала (`entries.raw`, последние 2000); без сети.
- Хвост фразы: начало текущей фразы (от последней запятой / начала строки до курсора, без пробелов в начале) ≥ 3 символов, курсор в конце строки или перед пробелом/знаком; фраза из истории начинается так же (без учёта регистра и «ё»), встречалась **≥ 2 раз**; хвост — её остаток в самом частом написании.
- Следующая фраза: курсор сразу после «, » (или «,») в конце строки; предыдущая фраза записи совпадает с фразой истории; следующая за ней в истории встречалась **≥ 2 раз** — серым вся она.
- Ранжирование: число употреблений, при равенстве — более свежая.
- Показ: хвост фразы, если он есть, иначе подсказки слов (0.2 beta 6, без изменений). В режиме «фраза» списка нет — только серый хвост.
- Клавиши: **→** и **Tab** — принять весь хвост; **Ctrl+→** — следующее слово хвоста (с пробелом перед ним); Esc, пробел-после-слова, стрелки движения — как сейчас. Enter без стрелки — перенос строки. Принятие — одна отмена (Ctrl+Z).
- Хвост фразы токенов не создаёт.
- Версия `0.3.0b2` / «0.3 beta 2»; `CHANGELOG.md` — «0.3 beta 2».

## Review Focus

1. Фраза встречалась 1 раз — хвоста нет (Task 1 `test_needs_two_uses`).
2. Хвост не предлагается посреди строки с текстом после курсора (Task 2 `test_no_tail_mid_line`).
3. Ctrl+→ берёт ровно одно слово и показывает остаток (Task 2 `test_ctrl_right_one_word`).
4. Хвост фразы и подсказка слова не показываются одновременно (Task 2 `test_phrase_tail_hides_word_list`).
5. Разбор записи после принятия хвоста — как если бы врач набрал её сам (Task 2 `test_accepted_tail_feeds_live_protocol`).

### Task 1: Привычки (`habits.py`)

**Files:** Create `orthofill/habits.py`; Modify `orthofill/journal.py` (`raw_notes(preset_id, limit) -> list[str]`, новые первыми), `orthofill/controller.py` (`continuation(text_before) -> str`); Test `tests/test_habits.py`.

**Interfaces:**
- `phrases_of(raw: str) -> list[str]` — фразы записи: по `,` `;` и переводам строк, без пробелов по краям, пустые выброшены.
- `class Habits(notes: list[str])` — `notes` новые первыми; `.tail(prefix: str) -> str` (остаток фразы или `''`); `.next_phrase(prev: str) -> str` (следующая фраза или `''`).
- `continuation(text_before: str, habits) -> str` — что показать серым: если текст кончается на `,`/`, ` — следующая фраза (с пробелом впереди, если после запятой пробела нет); иначе — хвост текущей фразы.
- `Controller.continuation(text_before) -> str` — кэш `Habits` по `(preset_id, число записей)`.

- [ ] **Step 1: tests**

```python
NOTES = ['активация, лигатурная, замена дуги верх 18х25 тма, явка 6 нед',
         'активация, лигатурная, замена дуги верх 18х25 тма, перепел',
         'активация, самолиг, замена лигатур']

def test_tail_of_habitual_phrase():
    h = Habits(NOTES)
    assert h.tail('замена дуги') == ' верх 18х25 тма'
    assert h.tail('ЗАМЕНА д') == 'уги верх 18х25 тма'

def test_needs_two_uses():
    assert Habits(NOTES).tail('замена лиг') == ''

def test_next_phrase():
    h = Habits(NOTES)
    assert h.next_phrase('активация') == 'лигатурная'
    assert h.next_phrase('лигатурная') == 'замена дуги верх 18х25 тма'

def test_continuation():
    h = Habits(NOTES)
    assert continuation('активация, лигатурная, ', h) == 'замена дуги верх 18х25 тма'
    assert continuation('активация,', h) == ' лигатурная'
    assert continuation('активация, замена ду', h) == 'ги верх 18х25 тма'
    assert continuation('активация, за', h) == ''            # < 3 символов

def test_controller_continuation(ctl, order_xlsx):
    ctl.import_xlsx(order_xlsx)
    for raw in NOTES[:2]:
        ctl.generate(raw)
    assert ctl.continuation('замена ду') == 'ги верх 18х25 тма'
```
