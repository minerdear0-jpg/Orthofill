# Orthofill 0.2 beta 4 — редактор пресета: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Править пресет прямо в программе — дерево с поиском и свойства, коды ID_CLASS с каскадом в эталоны и словарь, проверка классификатора, черновик со сверкой эталонов и сохранением, не теряющим правок главного окна.

**Architecture:** Вся логика — без Tk: `codes.py` (коды и каскад над `Workbook`), `lint.py` (проверка классификатора), `draft.py` (черновик: команды, отмена, журнал операций для повтора при сохранении). `PresetStore.save_draft` пишет пункты из черновика, а эталоны и словарь берёт из базы и повторяет на них журнал операций. Окно `editor.py` — тонкий слой над `Draft`.

**Tech Stack:** Python 3.12, tkinter/ttk + sv-ttk (Treeview, PanedWindow, Notebook), sqlite3, pytest.

**Spec:** `docs/superpowers/specs/2026-10-22-orthofill-0.2b4-editor-design.md` (выпуск 0.2 beta 4 и «Решения по проверке описания»).

## Global Constraints

- Только tkinter/ttk + sv-ttk; без новых зависимостей.
- Схема базы не меняется (v2): `method`, `when_`, `default_code`, `words_json`.
- Код: раздел `\d`, группа/пункт `\d[a-zа-я]`, вариант `\d[a-zа-я]\d+` (`workbook._CODE_RE`); уровень = длина (`workbook._level`).
- Простой режим — без кодов, JSON и ключей правил; подписи — `METHOD_LABELS`, `WHEN_LABELS`.
- Условия/правила не добавляют строк, которых не было в записи (анти-цель; в beta 4 правила не меняются).
- Несохранённое не теряется без вопроса.
- Версия выпуска — `0.2.0b4` / «0.2 beta 4»; `CHANGELOG.md` — раздел «0.2 beta 4» сверху (тест `test_changelog_top_is_current_version`).
- Все тексты интерфейса — по-русски, простыми словами врача.
- Тесты окна — на настоящем Tk (`tests/test_ui.py`, фикстура `app`); события клавиш — после `root.update()`.

### Task 1: Коды ID_CLASS и каскад (`codes.py`)

**Files:**
- Create: `orthofill/codes.py`
- Test: `tests/test_codes.py`

**Interfaces:**
- Consumes: `Workbook`, `Item`, `_CODE_RE`, `_level` из `workbook.py`.
- Produces:
  - `CodeMap = dict[str, str]` — старый код → новый (включая детей).
  - `next_code(wb, parent: str | None, level: int) -> str` — свободный код: раздел — следующая цифра; группа/пункт — следующая свободная буква раздела (`a…z`, пропуская занятые, учитывая коды-сироты `4h1` как занятую `h`); вариант — max номер + 1.
  - `code_error(wb, old: str, new: str) -> str | None` — `None` если можно; иначе текст: «код не по формату (1, 1a, 1a1)», «другой уровень: …», «нет группы «4x»», «код «4b2» уже занят».
  - `rename_map(wb, old: str, new: str) -> CodeMap` — `old → new` и все потомки с заменой префикса.
  - `swap_map(a: str, b: str, wb) -> CodeMap` — обмен двух кодов одного уровня (с потомками).
  - `renumber_map(wb, parent: str) -> CodeMap` — дети `parent` по текущему порядку: варианты 1, 2, 3…; группы раздела a, b, c… (без пропусков; сироты-пункты раздела не перенумеровываются). Только изменившиеся коды.
  - `apply_map(wb, m: CodeMap) -> None` — меняет `Item.id`, `parent`, `by_id`, `children` (перенос в другую группу — в конец её детей), `default` групп, `ReferenceCase.lines` коды, `DictEntry.code`. Порядок `wb.items` при переносе: пункт встаёт после последнего пункта нового родителя.

Правила (из описания, таблица «Проверка классификатора»):
- `dup_row` (error): одинаковая `row_text` у двух пунктов; `code` = коды через запятую.
- `dup_in_group` (error): два варианта одной группы с одинаковым текстом.
- `jaw_order` (warning): группа с вариантами «верхн» и «нижн», у которой вариант «верхн» имеет больший номер, чем «нижн», а у большинства таких групп пресета — наоборот. `code` = `'4p1,4p2'` (нижний, верхний).
- `gap` (info): номера вариантов не 1..N подряд.
- `no_default` (info): группа с `when`/`always`-поведением (способ выбора `words` и нет `default`) — сведение «нет варианта по умолчанию»; группы со встроенным правилом не помечаются.
- `empty_group` (warning): `level == 2`, не сирота, `method` задан, детей нет.

### Task 3: Черновик пресета (`draft.py`)

**Files:**
- Create: `orthofill/draft.py`

- Test: `tests/test_draft.py`

**Ruling (план):** п. 3 описания говорит «строки эталонов становятся строками без кода — эталон покажет ✗». Но `check_references` строки без кода **не проверяет** — эталон молча прошёл бы. Поэтому строки удалённого пункта **сохраняют код**; сверка видит недостающий код и показывает ✗ с текстом строки эталона. Обновить п. 3 описания этим текстом.

**Interfaces:**
- Consumes: `codes.*` (Task 1), `engine.check_references`, `engine._guess_kind`, `engine._effective_when`, `render.join_group`, `addition.row_text`, `PresetStore.norm_word`.
- Produces:
  - `Op` — элемент журнала: `('codes', CodeMap)`, `('text', old_row: str, new_row: str, code: str)`, `('del_item', code)`, `('del_ref', case_id)`, `('accept_ref', case_id, lines)`, `('del_word', word)`, `('import', None)`.
  - `class Draft(wb: Workbook, preset_id: int)`:
    - `.wb` — рабочая копия (`copy.deepcopy`), `.ops: list[Op]`, `.changed: int` (число команд после последнего сохранения), `.imported: Workbook | None`.
    - `can_undo / can_redo`, `undo()`, `redo()` — снимок `(wb, ops)` на команду.
    - `add(parent: str | None, after: str | None, text: str, level: int) -> str` — код через `next_code`; вставка в `items` после `after` (или в конец родителя).
    - `delete(code) -> None`; `impact(code) -> tuple[int, int]` — (эталонов, слов врача), включая потомков.
    - `move(code, delta: int) -> bool` — ↑↓ среди детей родителя; меняет порядок `items`, не коды.
    - `set_text(code, text) -> None` — закрепляет угаданное (`method` группы через `_guess_kind(it) or 'words'`, `when` пункта через `_effective_when`) **до** смены текста; переписывает строки эталонов с текстом, равным старой строке протокола пункта (`row_text` и текст самого пункта), и `DictEntry.item_text`; пишет `('text', …)`.
    - `set_prop(code, name: str, value) -> None` — `name` ∈ `method | when | default | words`.
    - `set_code(code, new) -> str | None` — ошибка (`code_error`) или `None`; если `new` занят соседом той же группы — вызывающий спрашивает и зовёт `swap(code, new)`.
    - `swap(a, b)`, `renumber(parent)` — через `codes`, пишут `('codes', map)`.
    - `delete_reference(case_id)`, `accept_reference(case_id)` (строки эталона := `build_protocol(wb, raw).lines`), `delete_word(word)`.
    - `import_wb(wb2)` — заменяет всё черновиком из файла (`('import', None)`, `imported = wb2`).
    - `check() -> list[CaseResult]` — `check_references(self.wb)`.
    - `replay(references, dictionary) -> tuple[list[ReferenceCase], list[DictEntry]]` — повторить `ops` по порядку над **базовыми** эталонами и словарём (для `save_draft`): коды → `apply_map`-логика для строк и словаря; `text` → переписать совпадающие строки и `item_text`; `del_item` → слова с кодом/текстом пункта удалить; `del_ref`/`accept_ref`/`del_word` — по `case_id`/слову, если есть. При `import` — вернуть эталоны и словарь черновика как есть.

Поведение (описание «Черновик, отмена, сохранение», «Вкладка «Слова врача»», «Проверка»):
- «Проверить эталоны» → вкладка «Эталоны (N)»: ✓/✗; у ✗ под строкой — «нет: …», «лишнее: …»; кнопки «Принять новое как эталон», «Удалить эталон».
- «Сохранить» без проверки или с ✗ — `_choice`: «Сломано эталонов: N из M. Сохранить всё равно?» [Сохранить] [Отмена].
- Закрытие с `changed` — [Сохранить] [Не сохранять] [Отмена].
- «Проверка (N)»: находки `lint` по порядку; двойной щелчок — выбрать пункт; у `jaw_order` — кнопка «Поменять коды местами» (`draft.swap`).
- «Слова врача (N)»: слово, пункт, (код — расширенный), добавлено, сработало; «Удалить»; двойной щелчок — к пункту.
- «Импорт xlsx…» в редакторе — `load_workbook_file` → `draft.import_wb` (с ошибками файла — показать и не менять). «Экспорт xlsx…» при `changed` — «Сначала сохранить?» → `save()` → экспорт как в главном окне.
- Ctrl+Z / Ctrl+Y в окне редактора (по физической клавише, как `_VK/_X11` в `ui.py`).
