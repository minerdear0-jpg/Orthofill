# Orthofill 0.5 beta 3 — холст протокола: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tab — карусель вариантов, Enter — подтверждение (заказчик: заполнение — Tab по деревьям и Enter). В режиме оболочки протокол справа — живой холст: ещё не написанные блоки — серый скелет (следующий — выделен), свой текст врача пишется прямо в протоколе и **не теряется** при пересборке, удалённая строка остаётся удалённой, строка оболочки под курсором подсвечивает своё место в протоколе.

**Architecture:** `orthofill/canvas.py` без Tk: модель холста — собранные строки протокола + правки врача (`OwnLine`: свой текст после строки-якоря, замена строки, удаление строки) + скелет; `compose` строит строки холста, `capture` извлекает правки из того, что сейчас в поле, `confirm_text` — текст для буфера и журнала (без скелета). Окно в режиме оболочки рисует холст тегами и после каждой правки протокола пересобирает модель — полоска «Обновить/Оставить» в режиме оболочки не нужна.

**Tech Stack:** Python 3.12, tkinter, pytest.

**Spec:** `docs/superpowers/specs/2026-10-22-orthofill-0.5-shell-design.md` — «Холст протокола (Canvas)», «Скелет протокола», «Отмена пункта» (удаление строки в протоколе), «Решения исполнителя по проверке описания» (правленая строка — свой текст при пункте); мокап `.superpowers/brainstorm/…/shell-animation-v2.html`.

## Global Constraints

- **Tab — пролистывание, Enter — подтверждение** (заказчик): в открытом списке Tab — следующий вариант по кругу (зажатый Tab — карусель, автоповтор клавиши), Shift+Tab — предыдущий; Enter — принять выбранный (лист — строка готова; группа — развернуть и сразу карусель веток, частый выбран). Пустая строка: Tab — карусель кандидатов (выбран первый — предсказание), Enter — принять предсказание. Набор — сужает список (он открыт сразу с выбранным первым); однозначный набор — Tab разворачивает сразу. Список соседей уровня (←/→ + остановка) — та же карусель, Enter — замена уровня.
- Карусель — без пересчёта дерева на каждый Tab: варианты считаются при открытии списка, Tab только двигает выделение.

- Только в режиме «Оболочка»; режим «через запятую» (заморозка, «Обновить/Оставить») не меняется.
- **Свой текст** — строка протокола, которой нет среди собранных: привязан к ближайшей собранной строке **выше** (её код; `None` — начало протокола); при пересборке встаёт после неё; якоря больше нет — в конец его раздела, нет и раздела — в конец, с пометкой «место свободного текста изменилось — проверьте».
- **Правленая собранная строка** — свой текст, **заменяющий** эту строку (пока строка с этим кодом есть в протоколе).
- **Удалённая собранная строка** — остаётся удалённой при пересборке (пока запись не очищена); это отмена пункта без ветки «нет» (Spec).
- Вид: свой текст — тег `own` (фон `#fff8e5`, слева полоса `#b88a00` — `lmargin`/`spacing`); скелет — строка-заглушка (пробелы) с фоном `#e8e7e2`; следующий блок — фон `#dbe7f3`; подсветка строки оболочки — тег `hl` (фон `#e3eef7`).
- **Скелет**: пункты разделов (группа или отдельный пункт), которых ещё нет в протоколе и которые врач обычно пишет (`PathStats.usual`), плюс первый кандидат предсказания (`predict(...)[0]`, 0.5 b2) — он «следующий»; стоят на своём месте по порядку файла. Нет истории — только «следующий».
- **В буфер и журнал скелет не попадает никогда**; свой текст — попадает. Ctrl+Enter — `confirm_text`.
- Правки врача живут, пока запись не очищена (новый пациент) или не подтверждена Ctrl+Enter.
- Телеметрия: `canvas` `own` (символов), `replaced`, `removed` (сколько строк) — в `note_confirm` режима оболочки; без текста.
- Версия `0.5.0b3` / «0.5 beta 3»; `CHANGELOG.md` «0.5 beta 3».

## Review Focus

1. Врач написал свой текст после «Смена дуги…», потом добавил строку оболочки, и выше появилась новая строка протокола — свой текст остался после «Смена дуги…» (Task 1 `test_own_follows_anchor`, Task 3 `test_own_text_survives_new_line`).
2. Врач удалил собранную строку справа, потом дописал запись — строка не вернулась (Task 1 `test_removed_stays_removed`, Task 3 `test_deleted_row_stays_deleted`).
3. Скелет не попадает в буфер и журнал, даже если врач поставил курсор в серую строку и Ctrl+Enter (Task 3 `test_skeleton_never_copied`).
4. Набор в серую строку скелета — свой текст на этом месте, а не порча скелета (Task 3 `test_typing_into_skeleton_is_own`).
5. Ctrl+Z в протоколе — правки пересчитаны по тому, что видно, ничего «призрачного» не остаётся (Task 3 `test_undo_in_canvas`).

### Task 1: Модель холста (`canvas.py`)

**Files:** Create `orthofill/canvas.py`; Test `tests/test_canvas.py`.

**Interfaces:**
- Consumes: `render.Row` (`text`, `codes`, `section`, `check`).
- Produces:
  - `OwnLine(anchor: str | None, text: str, replaces: bool = False)`; `Edits(own: list[OwnLine], removed: set[str])`.
  - `CanvasLine(text: str, kind: str, code: str | None, row: Row | None)` — `kind`: `row` · `own` · `skeleton` · `skeleton_next`; `code` — первый код строки протокола / якорь / код блока скелета.
  - `compose(rows: list[Row], edits: Edits, skeleton: list[tuple[str, bool]], order: dict[str, int], section_of: dict[str, str]) -> tuple[list[CanvasLine], list[str]]` — строки холста и предупреждения (перемещённый свой текст); `skeleton` — (код блока, следующий?); `order` — индекс кода в `wb.items`.
  - `capture(lines: list[tuple[str, str | None, str | None]]) -> Edits` — строки поля: (текст, код собранной строки или `None`, её исходный текст или `None`); собранные коды, которых больше нет среди строк, — в `removed` (передаётся как `shown: list[str]` — коды, показанные при последней отрисовке: `capture(lines, shown)`).
  - `confirm_text(lines: list[CanvasLine]) -> str` — без скелета.

- [ ] **Step 1: tests** — `test_compose_rows_only`; `test_own_follows_anchor` (own после 4b; новые строки 4a выше — own всё равно сразу после 4b); `test_replaced_row` (замена 4f → текст врача на месте строки 4f); `test_removed_stays_removed` (removed {'4j'} → строки 4j нет); `test_anchor_gone_moves_to_section_end` (якорь 4b исчез → own в конце раздела 4 + предупреждение «проверьте»); `test_capture_roundtrip` (compose → строки поля → capture == исходные Edits); `test_capture_edit_and_insert` (изменённая собранная строка → replaces; вставленная строка → own с якорем выше; первая строка поля — своя → якорь `None`); `test_capture_removed` (показан 4j, в поле нет → `removed == {'4j'}`); `test_skeleton_positions` (блок 3f стоит между строками разделов 3 по порядку файла); `test_confirm_text_without_skeleton`.
- [ ] **Step 2–4:** RED → implement → `uv run pytest -q` (код возврата 0).
