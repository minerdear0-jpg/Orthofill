# Orthofill 0.3 beta 3 — SmartPhrase / SmartList: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `.имя` раскрывается в фразу врача со списками выбора на месте переменных частей (как SmartPhrase/SmartList в Epic); программа сама предлагает сделать фразой то, что врач пишет снова и снова с разными числами/челюстями.

**Architecture:** `phrases.py` без Tk: шаблон `замена дуги {верх|низ|обе} {18х25|16х25}` (поля — списки значений, первое — самое частое), разбор/вывод шаблона, поиск «форм» фраз в истории (совпадают до чисел и челюстей ≥ 5 раз → шаблон). Хранение — таблица `phrases` (схема v4) и лист xlsx «Фразы»; фразы — часть пресета (черновик редактора, вкладка «Фразы»). Окно — `HintBox`: `.имя` в подсказках; раскрытие — режим полей (Tab — следующее поле, ↓/↑ — значение).

**Tech Stack:** Python 3.12, tkinter, sqlite3, openpyxl, pytest.

**Spec:** `docs/superpowers/specs/2026-10-22-orthofill-0.3-smart-input-design.md` — «0.3 beta 3», «Анти-цели».

## Global Constraints

- **Значения полей — слова врача** из его же записей («18х25», «верх»), а не тексты пунктов: разбор их уже понимает; токенов поля не создают (решение: проще и надёжнее, чем привязка к коду).
- Команда — `.имя` в начале строки или после пробела/запятой; «нед.», «0.016» команду не вызывают. В подсказках: «.замена → замена дуги {верх} {18х25} тма».
- Раскрытие (Tab / →): вставляется текст фразы; поля подсвечены, первое активно, его список значений — рамкой у поля (частые — сверху). **Tab** — следующее поле (значение остаётся), **↓/↑** — выбрать значение, **набор** — своё значение, **Esc** или Tab после последнего поля — выйти (подсветка снимается). Enter без стрелки — перенос строки; Ctrl+Enter — подтвердить протокол (поля снимаются).
- Предложение «сделать фразой»: после Ctrl+Enter, если фраза записи совпадает с ≥ 5 прошлыми с точностью до чисел и челюстей (и значения различаются) — в строке статуса «Вы часто пишете «замена дуги … тма» — сделать фразой «.замена»? [Да] [Нет]»; «Нет» — больше не предлагать эту форму (настройка журнала).
- Хранение: схема v4 — `phrases(preset_id, name, template, uses, created_at)`; лист xlsx «Фразы» (Имя | Шаблон | Использовано); экспорт ↔ импорт без потерь; фразы пишутся вместе с пунктами (черновик редактора).
- Версия `0.3.0b3` / «0.3 beta 3»; `CHANGELOG.md` «0.3 beta 3».

## Review Focus

1. «нед.», «0.016», «т.к.» не вызывают команду (Task 3 `test_dot_inside_word_is_not_command`).
2. Набор поверх поля заменяет значение поля, а не дописывает к нему (Task 3 `test_typing_replaces_field`).
3. Ctrl+Enter посреди раскрытой фразы — протокол подтверждён, подсветка полей снята (Task 3 `test_confirm_inside_phrase`).
4. Фраза с одинаковым значением во всех 5 записях не предлагается (это привычная фраза beta 2) (Task 2 `test_no_variation_no_proposal`).
5. Импорт xlsx с битым шаблоном (незакрытая `{`) — ошибка с ячейкой, пресет не меняется (Task 1 `test_bad_template_names_cell`).
