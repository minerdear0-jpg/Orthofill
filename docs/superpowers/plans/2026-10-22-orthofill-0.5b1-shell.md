# Orthofill 0.5 beta 1 — запись как оболочка: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Включаемый переключателем режим «Оболочка»: строка записи — путь по дереву пресета (`Лечение › Смена дуги на верхней челюсти › на верхней челюсти 0.016×0.025" NiTi`), сокращения разворачиваются Tab как в Cisco IOS, `?` — ветки, стрелки — как в fish; протокол собирается из путей без разбора и угадывания; отмена пункта — ветка «нет» из xlsx.

**Architecture:** `orthofill/shell.py` без Tk: сопоставление набранных слов с деревом (`resolve`) и разбор готовой строки в путь (`parse_line`). `orthofill/shellproto.py`: протокол из путей тем же `render_rows`, умолчаниями, условиями и парами, что движок. `orthofill/shellbox.py`: поведение поля записи в режиме оболочки (вместо `HintBox`). Строка в поле — сама истина (текст пути): журнал, эталоны, диагностика хранят её как есть.

**Tech Stack:** Python 3.12, tkinter, pytest.

**Spec:** `docs/superpowers/specs/2026-10-22-orthofill-0.5-shell-design.md` — «Решения заказчика», «Оболочка», «Стрелки», «Отмена пункта», «Переход», «Решения исполнителя по проверке описания», «Анти-цели».

## Global Constraints

- Разделитель уровней в строке — ` › ` (пробел, U+203A, пробел); его ставит только оболочка.
- Узел пути — **точный текст пункта** пресета (`' '.join(text.split())`), без сокращений.
- Совпадение слова: начало любого слова текста узла (нижний регистр, «ё»→«е»); формы — общее начало ≥ 3 букв и ≥ длины набранного − 1 («дуга»→«дуги»); числа — по цифрам: `16` ≈ `0.016`, `16х25` ≈ `0.016×0.025` (х/x/×/*, точка и ведущие нули не важны); синонимы — слова словаря врача (`DictEntry.word` → `code`). Смысловых совпадений нет.
- Набранные слова — фильтры «И» по ещё не выбранной части пути на любом уровне, порядок слов — не убывающая глубина. Неоднозначно — варианты, без догадки.
- Порядок вариантов в 0.5 b1 — порядок файла (`wb.items`); частоты и предсказание следующей строки — 0.5 b2.
- Ветка «нет»: дочерний пункт с текстом «нет» (после `norm`, без точки) — не вариант, а отмена родителя; в `children` не входит, хранится в `Item.cancel`.
- Режим «Оболочка» — флажок «Оболочка» рядом с «Подсказки», настройка журнала `shell:{preset_id}`; в режиме оболочки подсказки 0.2 b6, хвосты фраз 0.3 b2 и `.фразы` 0.3 b3 не работают; режим «как раньше» не меняется.
- Свободного текста в оболочке нет: строка без ` › `, не дошедшая до листа или не найденная в дереве — в протокол не попадает, предупреждение «строка N не понята: …».
- Телеметрия (0.4): `note_confirm` получает `mode: 'shell'|'comma'`; события `shell` (см. Task 6).
- Версия `0.5.0b1` / «0.5 beta 1»; `CHANGELOG.md` «0.5 beta 1».

## Review Focus

1. В режим оболочки вставлена старая запись через запятую — ничего не теряется молча: каждая непонятая строка — предупреждение, протокол только из умолчаний (Task 3 `test_comma_note_in_shell_warns`).
2. Пункт переименован в редакторе после того, как строка набрана — строка не понята, предупреждение, без падения (Task 3 `test_renamed_item_line_warns`).
3. Две строки выбирают разные варианты одной группы «ИЛИ» — обе в протоколе с «проверьте», а не молча последняя (Task 3 `test_two_or_variants_flagged`).
4. Строка «нет» и строка с вариантом той же группы — конфликт: «проверьте», пункт остаётся (Task 3 `test_cancel_and_pick_conflict`).
5. `?` в русской раскладке (Shift+7) не вставляется в текст, а открывает ветки; Tab/Enter на пустой строке ничего не ломают (Task 4 `test_question_not_inserted`, `test_tab_on_empty_line`).

### Task 2: Сопоставление строки с деревом (`shell.py`)

**Files:** Create `orthofill/shell.py`; Test `tests/test_shell.py`.

**Interfaces:**
- Consumes: Task 1 `Item.cancel`.
- Produces:
  - `SEP = ' › '`; `Path = tuple[str, ...]` (коды от раздела до узла).
  - `children_of(wb, code: str | None) -> list[Item]` — ветки узла (раздел → пункты; группа → варианты + «нет»; пункт с `cancel` → только «нет»); `None` — разделы.
  - `parse_line(wb, line: str) -> Path | None` — строка с ` › ` в точный путь (текст каждого уровня равен тексту узла после `' '.join(split())`); иначе `None`.
  - `format_path(wb, path: Path) -> str`.
  - `resolve(wb, done: Path, typed: str, synonyms: dict[str, str]) -> Resolution` где `Resolution(leaves: list[Path], common: Path, choices: list[Path], bad_word: int | None)`: `leaves` — подходящие пути до листьев (или до пунктов без детей) внутри `done`, по порядку файла; `common` — общий префикс (`Tab` разворачивает до него; один лист — весь путь); `choices` — узлы, где совпало **последнее** набранное слово (самые глубокие, без повторов), путём от раздела — их показывает список, когда `common` не дошёл до однозначного; `bad_word` — индекс первого слова, после которого кандидатов нет.
  - `is_leaf(wb, path) -> bool` — последний узел без веток (лист, «нет» или пункт без детей и без `cancel`).

- [ ] **Step 1: tests** (на `order.xlsx`)

```python
def test_unique_word_anywhere(wb):        # «лигатурная» → один лист 2b2, путь вверх достроен
    r = resolve(wb, (), 'лигатурная', {})
    assert r.leaves == [('2', '2b', '2b2')] and r.common == ('2', '2b', '2b2')

def test_short_prefix_is_ambiguous(wb):    # «лиг»: лигатурная / лигатур / лигатурой — не угадывать
    r = resolve(wb, (), 'лиг', {})
    assert {p[-1] for p in r.choices} == {'2b2', '4d', '4e', '4h1'} and len(r.leaves) > 1

def test_ambiguous_shows_matched_nodes(wb):   # «ду» — узлы, где совпало слово, с путём
    r = resolve(wb, (), 'ду', {})
    assert {p[-1] for p in r.choices} == {'1c', '1d', '3e2', '4b', '4c', '4g', '4h1', '4h2', '5c'}
    assert r.common == ()

def test_second_word_narrows(wb):         # «ду вер» → группа 4b (21 вариант)
    assert resolve(wb, (), 'ду вер', {}).common == ('4', '4b')

def test_numbers(wb):                      # внутри 4b: «16х» → 4 материала; «16х25 ni» → 4b5
    assert [p[-1] for p in resolve(wb, ('4', '4b'), '16х', {}).leaves] == ['4b5', '4b10', '4b14', '4b18']
    assert resolve(wb, ('4', '4b'), '16х25 ni', {}).common[-1] == '4b5'
    assert resolve(wb, ('4', '4b'), '16x25 ni', {}).common[-1] == '4b5'
    assert '4b2' in [p[-1] for p in resolve(wb, ('4', '4b'), '16', {}).leaves]

def test_inflection(wb):                   # «дуга» подходит к «дуги»
    assert resolve(wb, (), 'дуга верх', {}).common == ('4', '4b')

def test_bad_word(wb):                     # «эластики кв» → bad_word == 1, leaves == []
    r = resolve(wb, (), 'эластики кв', {})
    assert r.bad_word == 1 and r.leaves == []

def test_synonym(wb):                      # словарь «торк» → 4g3
    assert resolve(wb, (), 'торк', {'торк': '4g3'}).common == ('4', '4g', '4g3')

def test_no_meaning_guess(wb):             # «хор» не находит «удовлетворительная»
    assert resolve(wb, (), 'гигиена хор', {}).leaves == []

def test_parse_and_format_roundtrip(wb):
    line = format_path(wb, ('4', '4b', '4b5'))
    assert line == 'Лечение: › Смена дуги на верхней челюсти › на верхней челюсти 0.016×0.025" NiTi'
    assert parse_line(wb, line) == ('4', '4b', '4b5')
    assert parse_line(wb, 'лигатурная, перепел') is None
```

### Task 3: Протокол из путей и режим в контроллере

**Files:** Create `orthofill/shellproto.py`; Modify `orthofill/engine.py` (`check_references`: эталон со ` › ` — через `shell_protocol`), `orthofill/controller.py` (`shell_mode`, `preview`/`generate`/`find_unknown` в режиме оболочки); Test `tests/test_shellproto.py`.

**Interfaces:**
- Consumes: Task 2 `parse_line`, Task 1 `Item.cancel`.
- Produces:
  - `shell_protocol(wb, raw: str) -> Protocol` — каждая непустая строка: `parse_line`; лист-вариант → выбран в своей группе (группа «И» — все выбранные, «ИЛИ» — если выбрано больше одного, все с «проверьте»); лист-пункт → выведен; «нет» → родитель отменён (нет строки, нет умолчания). Группа без строки — её вариант по умолчанию (`ctx.default(...)` как в движке); пункты «всегда» — выводятся, если не отменены; условия — `logic.evaluate` с `Facts(known=выбранные варианты по группам, mentioned=коды строк и их групп)`; пары «не вместе» — как `_check_pairs`. Непонятая строка → предупреждение `строка {N} не понята: «{строка[:40]}»`. Отмена и выбор в одной группе → оба остаются: выбранное выводится, «проверьте» `отменено строкой «нет» — проверьте`.
  - `Controller.shell_mode: bool` (свойство: настройка `shell:{preset_id}` == '1'); `Controller.set_shell_mode(on: bool)`; в режиме оболочки `preview`/`generate` строят `shell_protocol`, `find_unknown` возвращает спаны непонятых строк (вся строка).
