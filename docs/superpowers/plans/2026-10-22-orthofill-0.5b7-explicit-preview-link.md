# Orthofill 0.5 beta 7 — «всегда» решает врач, просмотр вариантов, связь записи и протокола: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** (1) Обязательные строки — из идеальных результатов пресета (E–F), без строк, попавших в результат из-за слов записи примера (заказчик 22.10; окно подтверждения — отменено). (2) В оболочке справа — «Просмотр» полного текста варианта карусели, в самой карусели — отличающаяся часть вариантов (3e1/3e2 «Слизистая…» неразличимы). (3) Связь записи и протокола: цветные номера строк слева и справа (A) и колонка «откуда» у строки протокола (C); щелчок по строке протокола — курсор на её строку записи. (4) Раскраска записи в оболочке (заказчик: «ввод размечать наглядным цветом — родитель свойств имеет цвет, выделение и т. д.»; мокап `shell-colors.html`).

**Architecture:** (1) `Controller.always_review(pid) -> list[AlwaysItem]` и `save_always(pid, on: set[str])` (явное `when` для всех отдельных пунктов разделов, через черновик/`PresetStore`); окно `AlwaysDialog` — при активации пресета, у которого есть отдельные пункты без явного `when`. Движок не меняется: угадывание остаётся только для пресетов, где врач ещё не ответил («Позже»), с предупреждением в статусе. (2) `orthofill/distinct.py` без Tk: отличающаяся часть текстов соседей и спаны отличий; `ShellBox` подписывает строки карусели отличающейся частью и показывает панель «Просмотр» (place справа, как F2) пока карусель открыта. (3) `orthofill/links.py` без Tk: номера строк записи и источник каждой строки протокола; окно рисует две узкие колонки-холста (`tk.Canvas`) слева от поля записи и слева от протокола, синхронно с прокруткой; текст протокола не меняется (копирование и холст 0.5 b3 не затронуты).

**Tech Stack:** Python 3.12, tkinter, pytest.

**Spec:** решения заказчика 22.10 (диагностика `diag/2026-10-22-b6/`, мокапы `.superpowers/brainstorm/…/preview-and-always-v2.html`, `link-input-output.html` — выбраны: «всегда» (а), просмотр A, связь A+C).

## Global Constraints

- **«Всегда» — только явно.** Отдельные пункты разделов (уровень 2, без вариантов, не «сироты») с `when is None` — «не решено». Окно «Какие строки выводить в каждом протоколе?» — список по разделам; галочка заранее, если пункт есть не меньше чем в 2 эталонах и больше чем в половине; иначе без галочки, с «⚠ в N из M — решите сами» (N из M эталонов). «Сохранить в пресет» → `when='always'` отмеченным, `when='mentioned'` остальным (запись в пресет, как сохранение редактора); «Позже» → окно не появляется до следующего запуска, статус «⚠ «Всегда» угадано по эталонам — подтвердите (Пресет → Что выводить всегда…)». Пункт меню пресета «Что выводить всегда…» — открыть окно в любой момент.
- Импорт xlsx без явного «когда» — снова «не решено» (окно при активации).
- **Просмотр (A)**: только режим «Оболочка»; панель справа `PREVIEW_W = 0.40` ширины тела окна, поверх (как F2), видна, пока открыта карусель; заголовок «Просмотр», путь, код, полный текст выделенного варианта с подсветкой отличия от соседних (фон `#fff1c2`), ниже — «Соседний вариант (код): …отличие». Закрылась карусель — панель скрыта. Если открыт протокол (F2) — просмотр поверх него, по закрытии карусели протокол снова виден.
- **Карусель**: подпись строки — отличающаяся часть, если у вариантов общее начало ≥ 20 символов: «…<хвост>»; иначе — как раньше.
- **Связь (A+C)**: только режим «Оболочка». Колонка слева от записи — номер строки записи в цветном кружке (цвет по номеру из 8 цветов палитры, по кругу) у готовых строк-путей. Колонка слева от протокола — тот же номер и цвет у строки, которая из этой строки записи, и «откуда» для остальных: «всегда», «по умолч.», «по условию», «из слов», «ваш текст»; скелет — пусто. Строка под курсором — подсветка с обеих сторон (уже есть). Щелчок по номеру или по строке протокола из записи — курсор на её строку записи.
- Колонки синхронны с прокруткой полей (`yscrollcommand`), пересчёт — после отрисовки протокола и после набора (не чаще 1 раза на 100 мс).
- **Раскраска записи** (только оболочка), теги поля записи: раздел — свой постоянный приглушённый цвет (`SECTION_COLORS` по порядку разделов: `#4d6a8a`, `#2f7a6a`, `#9a5b2e`, `#6b4fa0`, `#5a6b2f`, `#7a4f5a`, по кругу); группа — полужирная; лист — основной цвет, зелёная черта (как `shell_ok`); разделитель «›» — `#b9b8b1`; уровень, который сейчас выбирают (последний развёрнутый перед курсором при открытой карусели), — фон `#e3eef7`; набранное после « › » — фон `#fff1c2`; «не подходит» — красная волна (как сейчас). Пересчёт тегов строки — при её изменении, всех строк — при отрисовке/вставке (не чаще 1 раза на 100 мс).
- Версия `0.5.0b7` / «0.5 beta 7»; `CHANGELOG.md` «0.5 beta 7».

### Task 1: Обязательные строки — из идеальных результатов пресета

**Заказчик 22.10 (изменение плана):** «Обязательные строки будем брать из пресета — там они уже отражены: врач уже сам определил в идеальном конечном результате (E–F) то, что туда должно попасть, а в примерах (C–D) — то, что может попасть из классификатора». Окно «Что выводить всегда» — не делается. Случай 4o: в старом пресете врача идеальный результат примера содержал «Подвязывание…» без слов о нём в записи — по определению пресета это было обязательным; в текущем пресете строка убрана.

**Files:** Modify `orthofill/engine.py` (`_guess_when` — по доводам эталонов, `_ref_evidence` — кэш по содержимому); Test `tests/test_always.py`.

- [x] Правило: «всегда» — пункт есть в идеальном результате больше чем в половине примеров, где запись примера о нём не говорит; сказанный в записи примера — не довод за «всегда»; явное «когда» в пресете — главнее; без эталонов — всегда (как раньше).
- [x] Tests: `test_in_ideal_result_not_said_is_always`, `test_said_in_example_is_not_always`, `test_mixed_examples`, `test_explicit_when_wins`, `test_cached_per_preset`, `test_doctor_presets_unchanged`.

### Task 1b: «*» в ID_CLASS — обязательное свойство (решение заказчика 22.10)

«Если в ID_CLASS есть `*` — свойство по умолчанию сразу попадает в отчёт; в редакторе — чекбокс „Обязательное“».

- Код — без `*` (`2a*` → `2a`); `Item.star`; `Workbook.star_mode` — есть хоть одна звёздочка.
- Без звёздочек — как в Task 1. Со звёздочками само в отчёт идёт только: отмеченный пункт; отмеченный вариант — умолчание группы; отмеченная группа — её первый вариант (`engine.star_default`); жалоба — только отмеченная. Явное «всегда» из редактора тоже остаётся (решение врача). Правила-умолчания (гигиена, этап) выключены.
- База: `preset_items.star`, схема 5; выгрузка xlsx пишет `*` обратно; `Draft.set_prop(code, 'star', bool)`; редактор — «Обязательное (*) — сразу в протокол».
- Tests: `tests/test_star.py` (11). Commit `feat: «*» в ID_CLASS — обязательное свойство пресета (чекбокс в редакторе)`.
