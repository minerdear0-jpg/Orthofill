# Orthofill 0.2 beta 6 — подсказки в записи: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Подсказки при наборе записи в стиле VS Code: серый «хвост» лучшего слова и список у курсора; Tab принимает, быстрый ввод ничем не перехватывается; вставляется слово врача, справа — во что оно превратится.

**Architecture:** `hints.py` без Tk: кандидаты по началу слова из трёх источников (словарь врача, прошлые записи врача из журнала, слова пунктов пресета), ранжирование, «во что превратится». Окно: рамка `place()` внутри главного окна у `bbox('insert')` и серая метка-хвост поверх текста; клавиши — на поле записи.

**Tech Stack:** Python 3.12, tkinter/ttk + sv-ttk, sqlite3, pytest.

**Spec:** `docs/superpowers/specs/2026-10-21-orthofill-0.2-design.md` — «Этап 5. Подсказки в записи» (там же п. 6 «Цели» и клавиши); макет — `.superpowers/brainstorm/2866305-1792601460/content/presets.html`, блок 3, вариант 1 (IntelliSense + серый хвост), принят 21.10.

## Global Constraints

- Появляется с 3-й буквы слова; выключатель «Подсказки» (флажок в панели рядом с «Поверх окон», хранится в настройках журнала `hints`, по умолчанию вкл.).
- Клавиши: печать — фильтрует, ничего не вставляет; **Tab** — принять верхний (или выбранный); **↓/↑** — войти в список, только после этого **Enter** = принять; **Enter** без ↓ — перенос строки; **Ctrl+Enter** — сформировать (список закрывается, не перехватывается); **Esc** — закрыть; **Ctrl+Space** — открыть вручную; **пробел, запятая** — закрыть без вставки.
- Вставляется **слово врача**, не текст пункта; заменяет набранное начало слова.
- Хвост — метка поверх текста, не вставка (не ломает undo и `get()`).
- Список — `ttk.Frame` в главном окне через `place()` по `bbox('insert')`, не Toplevel; у нижнего края — вверх; при прокрутке поля, смене размера окна, потере bbox, уходе фокуса — закрывается.
- Только tkinter/ttk + sv-ttk. Версия — `0.2.0b6` / «0.2 beta 6»; `CHANGELOG.md` — «0.2 beta 6».
- Тесты окна — настоящий Tk (фикстура `app`).
- **ТРИЗ 22.10 (одобрено):** источник «из ваших записей» (журнал, по частоте); один кандидат — только серый хвост, без списка; «→ …» — только когда известно наверняка.

## Review Focus

1. Быстрый набор «перепел, явка 6 нед» + Enter без ↓ → в поле перенос строки, ничего не вставлено (Task 2 `test_enter_without_arrow_is_newline`).
2. Ctrl+Enter при открытом списке → протокол сформирован, в записи ничего не вставлено (Task 2 `test_ctrl_enter_not_intercepted`).
3. Набрано в английской раскладке «njh» → подсказка «торк» (Task 1 `test_wrong_layout`).
4. Поле прокрутили / окно сузили при открытом списке → список закрыт, не висит в чужом месте (Task 2 `test_closes_on_scroll_and_resize`).
5. Подсказки выключены → ни списка, ни хвоста, Tab — как раньше (Task 2 `test_toggle_off`).

### Task 1: Кандидаты подсказок (`hints.py`) и слова прошлых записей

**Files:**
- Create: `orthofill/hints.py`
- Modify: `orthofill/journal.py` (`raw_words`), `orthofill/controller.py` (`hints(prefix)`)
- Test: `tests/test_hints.py`

**Interfaces:**
- Produces:
  - `@dataclass Hint(word: str, becomes: str, kind: str)`; `kind` ∈ `'doctor'` («ваше слово» — словарь врача), `'history'` («из ваших записей»), `'item'` («пункт»).
  - `Journal.raw_words(preset_id: int | None, limit: int = 2000) -> dict[str, int]` — слова (нижний регистр, ≥3 букв, без чисел и служебных `vocab.SERVICE`) из `entries.raw` последних `limit` записей этого пресета → сколько раз встречались.
  - `build_index(wb, history: dict[str, int]) -> HintIndex` — один раз на пресет/обновление словаря.
  - `HintIndex.suggest(prefix: str, limit: int = 7) -> list[Hint]` — слова, начинающиеся с `prefix` (без учёта регистра, «ё»=«е»; если ничего — та же строка, переложенная из английской раскладки, как в `addition._EN_RU`); само слово, равное `prefix`, не предлагается; порядок: словарь врача → прошлые записи (по частоте) → слова пунктов; без повторов слова (берётся первый источник).
  - «Во что превратится»: словарь — `row_text` пункта слова; слово пункта, встречающееся в тексте **одного** пункта (или в его `words`), — `row_text` этого пункта; иначе `''`. Слова пунктов: из текстов пунктов и `Item.words`, ≥4 букв, без `SERVICE`/`FILLER`.
  - `Controller.hints(prefix) -> list[Hint]` — индекс кэшируется по `(preset_id, sha256 пресета, число записей журнала)`.

### Task 2: Список у курсора, хвост, клавиши

**Files:**
- Create: `orthofill/hintbox.py` (класс `HintBox` — рамка списка и хвост; знает поле `tk.Text` и главное окно)
- Modify: `orthofill/ui.py` (создать `HintBox` для `raw_txt`, флажок «Подсказки», закрывать при `generate`)
- Test: `tests/test_hints_ui.py`

**Interfaces:**
- Consumes: `Controller.hints` (Task 1).
- Produces: `HintBox(app, text_widget)` — `.visible -> bool`, `.items -> list[Hint]`, `.selected: int` (−1 — не входили в список), `.tail` (метка), `update()` (пересчитать по слову перед курсором), `open()` (Ctrl+Space), `close()`, `accept(i: int | None = None)`; привязки на поле: `<KeyRelease>` → `update`, `<Tab>`, `<Down>`, `<Up>`, `<Return>`, `<Escape>`, `<Control-space>` — возвращают `'break'` только когда список открыт и клавиша его (Return — только при `selected >= 0`). `App.hints_on` (BooleanVar), флажок «Подсказки».

Вид (макет, блок 3 вариант 1): строки списка — слово (набранная часть жирным), справа серым «→ <во что превратится>» и подпись вида («ваше слово» / «из ваших записей» / «пункт»); первая строка обведена (не выделена); внизу строка «Tab принять · ↓ выбрать · Esc закрыть»; узкое окно — во всю ширину поля. Хвост — серый остаток верхнего слова сразу после курсора. Один кандидат — только хвост, без списка (ТРИЗ, одобрено).

```python
def test_popup_and_tab_accepts(app):
    app.ctl.learn('торк', '4g3')
    _type(app, 'лигатурная, тор')
    hb = app.hint_box
    assert hb.visible and hb.items[0].word == 'торк' and hb.tail['text'] == 'к'
    _key(app, 'Tab')
    assert app.raw_txt.get('1.0', 'end-1c') == 'лигатурная, торк' and not hb.visible

def test_enter_without_arrow_is_newline(app):
    _type(app, 'перепел, яв')
    _type(app, 'к')                                   # «явк» — список открыт
    _key(app, 'Return')
    assert app.raw_txt.get('1.0', 'end-1c').endswith('явк\n')

def test_arrow_then_enter_accepts_second(app):
    app.ctl.learn('торк', '4g3'); app.ctl.generate('лигатурная, торцевание')
    _type(app, 'тор')
    _key(app, 'Down'); _key(app, 'Down'); _key(app, 'Return')
    assert app.raw_txt.get('1.0', 'end-1c') == 'торцевание'

def test_ctrl_enter_not_intercepted(app):
    app.ctl.learn('торк', '4g3')
    _type(app, 'лигатурная, тор')
    _key(app, 'Return', ctrl=True)
    assert app.out_txt.get('1.0', 'end-1c') and not app.hint_box.visible
    assert app.raw_txt.get('1.0', 'end-1c') == 'лигатурная, тор'

def test_escape_space_comma_close(app):
    app.ctl.learn('торк', '4g3')
    for k in ('Escape', 'space', 'comma'):
        app.raw_txt.delete('1.0', 'end'); _type(app, 'тор')
        _key(app, k)
        assert not app.hint_box.visible

def test_closes_on_scroll_and_resize(app):
    app.ctl.learn('торк', '4g3'); _type(app, 'тор')
    app.raw_txt.yview_scroll(1, 'units'); app.root.update()
    assert not app.hint_box.visible
    _type(app, ''); app.hint_box.update()
    app.root.geometry('500x700'); app.root.update()
    assert not app.hint_box.visible

def test_toggle_off(app):
    app.ctl.learn('торк', '4g3')
    app.hints_on.set(False); app._toggle_hints()
    _type(app, 'тор')
    assert not app.hint_box.visible and app.hint_box.tail['text'] == ''
    assert app.ctl.journal.get_setting('hints') == '0'
```
