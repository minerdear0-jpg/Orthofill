# Orthofill 0.4: телеметрия — поведение врача и скорость программы

Дата: 22.10.2026. Идея и решения заказчика из разговора 22.10.

## Зачем

Сейчас ошибки и неудобства видны через дни: врач приносит папку диагностики,
мы её разбираем. Телеметрия в реальном времени показывает то же через минуты:
где врач «тупит», что нажимает, когда ищет, что не нажимает, чем пользуется, а
чем — нет. Пример, который мы пропустили бы: Ctrl+V в русской раскладке «не
работал» в окне «Отметить ошибку» — в поведенческом журнале это сразу видно
(нажал — текст не изменился — нажал ещё раз — вставил мышью).

Главное — **паттерны во времени, а не снимок**: если врач сейчас не пользуется
подсказками, это может быть делом привычки — важна кривая привыкания по дням и
неделям. Принцип заказчика: **индивидуальность врача — метод ускорения**;
поведение — та же индивидуальность, только в действиях.

Вторая цель — **данные для решения «Python или Rust/C++»** (решено 22.10:
остаёмся на Python, переход — по данным): программа меряет свою скорость на
реальных компьютерах клиники (запуск, сборка протокола, подсказки, отклик
окна).

## Цели

1. Программа шлёт события на сервер заказчика в реальном времени, не замедляя
   ввод и ничего не теряя без сети.
2. Приёмник на сервере хранит события и показывает **страницу в реальном
   времени**: использование функций по дням, воронки, время на запись, правки,
   скорость, ошибки.
3. Те же данные — **в машинно-читаемом виде** (JSON) для разбора исполнителем.

## Не цели

- Облако, учётные записи, несколько организаций.
- Удалённое управление программой, обновления по сети.
- Перенос на другой язык (решение — по данным телеметрии позже).

## Анти-цели

- Набор, Ctrl+Enter или запуск ждут сеть.
- События молча теряются (нет сети, сервер выключен).
- Отправка при выключенной диагностике или без настроенного сервера.
- Закрытый ключ сертификата или ключи доступа — в репозитории.
- Программа доверяет любому сертификату (а не только своему серверу).
- **Обратный канал.** Сервер только принимает: ответ на отправку — лишь
  «принято N»; программа ничего с сервера не получает и не выполняет
  (заказчик: «на сервере только приём данных — проникнуть в канал нельзя,
  просто нет такого функционала»).
- **ФИО на сервере.** Если в тексте попалось ФИО — вырезается и не хранится
  (заказчик: «уважаем чужую частную жизнь»).

## Среда (заказчик)

- Сервер: **Debian**, отдельная виртуальная машина, **IP без домена**.
- HTTPS — **самоподписанный сертификат**, программа доверяет только ему
  (сертификат встраивается в программу).
- Данные обезличены (ФИО и прочих ПД нет — заказчик).
- Сервер **удалённый, через интернет** (заказчик) — отсюда защита ниже.
- **Текст уходит** (заказчик, 22.10): записи, протоколы, правки — как в
  локальной диагностике, после вырезания ФИО.

## Программа (клиент)

### Что пишется

Всё, что уже пишет диагностика (`generate`, `case`, `copy`, `learn`,
`unknown`, `preset_saved`, ошибки…), плюс **события поведения** — без
набранного текста (длины, виды, источники):

| Событие | Поля |
|---|---|
| `session_start` | версия, сборка, ОС, DPI/масштаб, размер окна, **время запуска** |
| `note_start` / `note_confirm` | время от первой буквы до Ctrl+Enter, число нажатий, символов, Backspace, пауз > 2 с, длина записи; чем подтвердил (Ctrl+Enter / кнопка / «Копировать») |
| `hint` | показана / принята (Tab, →, список, мышь) / проигнорирована / стёрта после принятия; источник (словарь, история, пункт), позиция выбранного, длина набранного начала |
| `habit` | хвост фразы показан / принят целиком / по слову (Ctrl+→) / проигнорирован |
| `smartphrase` | `.имя` показана / раскрыта / поле: выбрано из списка / своё / оставлено; выход (Esc, Tab, Enter) |
| `proposal` | «сделать фразой» показано / Да / Нет |
| `add_search` | «Добавить пункт»: длина запроса, нашлось / нет, выбран ли пункт |
| `protocol_edit` | ручная правка протокола до/после Ctrl+Enter (сколько строк), «обновить?» показано / Обновить / Оставить |
| `ui` | нажатия кнопок и пунктов меню (по имени), правое меню полей, горячие клавиши (какие), смена пресета, открытие редактора |
| `key_noop` | сочетание клавиш нажато, а текст/выделение не изменились (кандидат «не работает») |
| `perf` | время сборки черновика, подсказки, самопроверки, поиска форм (мс) |

У события: `id` (UUID — повтор не задваивается), `ts`, `install` (случайный
идентификатор установки, без ПД), версия, сборка, пресет.

События поведения пишутся и в локальную диагностику (папка `diagnostics/`) —
разбор возможен и без сервера.

### Вырезание ФИО

Модуль без зависимостей (`orthofill/scrub.py`), один и тот же в программе
(до отправки) и на сервере (перед записью в базу — вторая линия). Ищет во
всех строковых полях события:

- отчество (любой регистр): `-ович/-евич/-ич/-овна/-евна/-ична/-инична`
  вместе со стоящими рядом словами-именами — «Иванов Иван Иванович»,
  «иван иванович»;
- фамилию с инициалами: «Иванов И.И.», «И. И. Иванов»;
- имя из списка частых русских имён (~300, полные и краткие формы:
  «Мария», «Маша») — само и с соседним словом с заглавной буквы.

Найденное заменяется на `‹ФИО›`, у события — счётчик `scrubbed`. Слова
словаря врача и пресета в замену не попадают (эпонимы вроде «Энгл»).
Решение исполнителя: ложное срабатывание (лишнее `‹ФИО›`) дешевле
пропуска.

### Как отправляется

- События кладутся в очередь в памяти (не блокирует) и **сразу пишутся в
  локальный файл-очередь** (`telemetry/` рядом с журналом; JSON-строки).
- Фоновый поток раз в ~5 с (или при 100 событиях) отправляет пачку
  `POST https://<IP>:<порт>/v1/events` с ключом установки; ответ «принято» —
  пачка удаляется из файла-очереди. Нет сети / ошибка — повтор с растущей
  паузой (до минут); очередь ограничена по размеру (старые — в архив, не
  молча).
- TLS: доверие **только встроенному сертификату сервера** (`ssl` с этим
  сертификатом как единственным центром), проверка адреса — по IP в
  сертификате (SubjectAltName: IP).
- Включено, когда **включена «Диагностика»** и **задан сервер**. Без
  сервера — всё как сейчас (только локально). «Отметить ошибку» при
  выключенной диагностике — только локально, как сейчас (решение
  исполнителя).
- **Файл `telemetry.json`** (адрес `https://IP:порт`, ключ установки,
  сертификат сервера PEM, необязательное `doctor` — прозвище врача).
  Выдаёт его скрипт установки сервера. Где ищется, по порядку: рядом с exe
  → папка данных (`%LOCALAPPDATA%\Orthofill`, если рядом с exe писать
  нельзя) → встроенный в сборку (`build.ps1` встраивает, если файл лежит в
  папке проекта; в git не попадает — `.gitignore`). Смена IP или
  переустановка сервера — новый файл рядом с exe, без пересборки.
- Одна установка — один врач (у каждого своя программа и настройки);
  `doctor` — для группировки на странице.
- В «О программе» — строка «Телеметрия: отправлено N, в очереди M, сервер
  доступен / нет».

## Приёмник (сервер)

- Каталог `server/` в репозитории: служба на Python 3 (Debian), хранение —
  SQLite (WAL). Одна зависимость веб-сервера.
- `POST /v1/events` — пачка событий, ключ установки; повтор по `id` не
  задваивается. Ключ даёт **только запись**: прочитать им ничего нельзя.
  Перед записью — вырезание ФИО (вторая линия).
- `GET /` — **страница в реальном времени** (пароль администратора), живая
  лента событий и графики, обновляется сама.
- `GET /v1/report?from=&to=&install=` — сводка JSON (то же, что на странице) —
  **для исполнителя**; `GET /v1/events?type=&since=` — сырые события (JSON
  строки).
- Установка — один скрипт на Debian: пользователь службы, venv, сертификат с
  IP (openssl, SAN=IP), ключ установки и пароль страницы (генерируются, в
  репозиторий не попадают), служба systemd, порт (по умолчанию 8443).
  Скрипт выдаёт `telemetry.json` для программы.

### Защита (сервер в интернете)

- Открыт только порт приёмника (и SSH): файрвол (nftables).
- Ограничения: размер запроса (1 МБ), пачка ≤ 500 событий, частота — по
  IP и по ключу (лишнее — 429); неверный ключ или пароль — пауза, после
  серии — блок IP на время.
- Пароль страницы — длинный случайный, только по HTTPS; сравнение за
  постоянное время.
- Служба — от отдельного пользователя без прав, `systemd` с песочницей
  (`ProtectSystem=strict`, `NoNewPrivileges` и т. п.).
- Хранение — 180 дней, потом удаляется (решение исполнителя, меняется в
  настройках сервера).

### Страница: что видно

- **Сейчас**: живая лента событий, кто на связи, последние ошибки.
- **Использование функций по дням/неделям**: доля записей с подсказками,
  хвостами фраз, `.фразами`, «Добавить пункт», ручными правками — кривые
  привыкания.
- **Воронки**: подсказка показана → принята / проигнорирована / стёрта;
  фраза → раскрыта → поля выбраны / оставлены; «Добавить пункт» → нашлось →
  выбрано.
- **Время на запись** (медиана, разброс) по дням; паузы; Backspace.
- **Узкие места**: `key_noop` (не сработавшие сочетания), поиски без
  результата, непонятые слова (топ), «обновить?» → «Оставить».
- **Скорость**: запуск, черновик, подсказки — медиана и 95-й процентиль по
  версиям и компьютерам.
