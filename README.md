# Orthofill 0.2 beta 3

Краткая запись ортодонта → полный протокол приёма по пресету (типу карточки) →
буфер обмена → вставка в служебное ПО.

> Программа формирует черновик протокола; ответственность за содержание несёт врач.

## Запуск

1. Распакуйте `Orthofill-<версия>-portable.zip` (например, `Orthofill-0.2beta3-portable.zip`) в любую папку (например, `D:\Orthofill`).
2. Запустите `Orthofill\Orthofill.exe`. Установка не нужна.
3. При первом запуске нажмите **«Пресет» → «Импорт xlsx…»** и выберите файл
   (в папке лежит пример `order.xlsx`). Из файла получится пресет, программа его
   запомнит. Если вы обновляетесь с 0.1, пресет из прежнего файла создастся сам.

Пресеты, эталоны, журнал и настройки хранятся в базе `orthofill.db` рядом с
программой (если в эту папку нельзя писать — в `%LOCALAPPDATA%\Orthofill`).
Файл xlsx после импорта программе не нужен — его можно править в Excel и
импортировать снова.

## Работа на приёме

1. Наберите краткую запись, например:
   `лигатурная, рабочий, по молярам 1, замена дуги верх 18 25 нити, низ 14 нити, перепел, явка 4 нед`
2. Протокол справа **пишется сам** по мере набора (черновик — в буфер не идёт).
   Принятые подсказкой слова подсвечены зелёным — программа поняла их так, как
   показано в подсказке.
3. Проверьте протокол. При необходимости исправьте прямо в окне (после правки
   протокол сам больше не обновляется — полоска «обновить?»).
4. **Ctrl+Enter** — подтвердить: в буфер уходит протокол, как он виден справа.
5. Вставьте в служебное ПО (**Ctrl+V**).

Как выглядит протокол:

- одна мысль — одна строка: «Смена дуги на верхней челюсти 0.018×0.025" NiTi.»,
  «Явка на следующую активацию через 6 недель.»; разделы — жирным, с отступом;
- **оранжевая полоса слева** у строки — программа здесь **сама что-то
  предположила** (сторона класса, челюсть дуги, ближайший срок явки, вариант
  по словам записи). Проверьте такую строку; если поправите её — полоса исчезнет.
  В буфер полосы и пометки не попадают.

Под протоколом:

- оранжевым — **почему** строки помечены («! Соотношение моляров справа… — сторона
  не указана») и что упомянуто, но не распознано — это допишите вручную;
- серым — что подставлено **по умолчанию**, потому что не было написано
  (например, «явка 4 нед», «гигиена удовлетворительная»).

### Если программа что-то пропустила

- Слова записи, которые программа **не поняла**, после Ctrl+Enter подчёркнуты
  оранжевым. Нажмите на такое слово, выберите в списке нужный пункт — он встанет
  в протокол на своё место, а слово программа **запомнит**: в следующий раз оно
  будет понято само.
- Пропущенный пункт без «своего» слова — строка **«+ Добавить пункт»** над
  протоколом: начните печатать (можно в любой раскладке), выберите стрелками и
  Enter. Ваши правки в протоколе сохранятся, протокол сразу скопируется.
- После добавления программа спросит: «Это было «…»?» — **Да**, **Другое слово…**
  (выберите слово кнопкой или выделите фразу мышью → «Запомнить выделенное») или
  **Пропустить**. Работать с протоколом вопрос не мешает.
- Запомненное слово подсвечено зелёным; **«Отменить»** в строке статуса забывает его.
  Если после нового слова какой-то эталон перестал совпадать, программа скажет об
  этом — проверьте или отмените.
- Слова «без …», «… отменён» отменяют и выученные слова.

Сверху окна крупно написано имя выбранного пресета — проверьте, что это нужный
тип карточки.

**«Поверх окон»** — окно Orthofill не прячется за служебным ПО. Окно можно сделать
узким — оно само перестроится (запись сверху, протокол снизу).

## Как писать запись

Порядок — любой, запятые желательны, но не обязательны. Дуга распознаётся по слову
«дуга» или, без него, по размеру с материалом (`низ 0.014 NiTi`) или сечению с челюстью
(`верх 16х25`). Всё, что программа увидела, но не поняла, она покажет оранжевым.
Программа понимает, например:

| Что | Примеры |
|---|---|
| Тип системы | лигатурная, самолигирующая |
| Этап | начальный / нивелирование, рабочий, детализация |
| Классы | по молярам 1, 2 класс по клыкам, моляры II |
| Дуги | верх 16х25 нити; низ 0.014 NiTi; обе 17*25 тма; в/ч 19/25 сталь, н/ч 14 cuniti |
| Лигатуры, подвязывание | смена лигатур на нижней; подвязывание на верхней |
| Эластики | перепел, лиса, медведь… (как в классификаторе) |
| Юстировка | изгиб второго порядка; торк (= изгиб третьего порядка) |
| Явка | явка 6 нед, через 2 недели |
| Состояние | гигиена неудовлетворительная, эрозия, без динамики |
| Жалобы | отклеился брекет, выход дуги, перелом дуги |

Разделитель размера дуги — любой: `16x25`, `16х25`, `16*25`, `16-25`, `16/25`, `16 25`.
Раскладку можно путать: `СuNiTi` с русской «С» тоже распознается.

### Оболочка (запись путями по пресету)

Флажок **«Оболочка»** (запоминается для пресета) превращает запись в строки-пути
по дереву пресета: `Лечение: › Назначены межчелюстные эластики › Перепел`.
Сокращения разворачивает **Tab**, **?** показывает ветки уровня, **↑/↓** —
выбор, **Enter** — строка готова, **←/→** — по уровням (остановка на уровне
показывает соседей для замены). Свободного текста в оболочке нет — свои слова
пишите в протоколе справа. Отмена пункта — вариант «нет» у пункта в xlsx.

На пустой строке серым — следующий по файлу пункт из вашего обычного набора
(Tab — принять, Ctrl+→ — по уровню, ? — всё дальше по файлу, ★ — обычное).
Порядок — всегда ваш xlsx; из истории программа узнаёт только, что вы обычно
пишете и какие варианты выбираете чаще (они — сверху списков).

**Tab** листает варианты по кругу (Shift+Tab — назад), **Enter** подтверждает,
**→** в конце строки дописывает серую подсказку (как в fish), **?** — варианты уровня.
Пишите как удобно: кириллицей или латиницей, слитно или раздельно, в любой
раскладке («кунити» = «CuNiTi» = «cu ni ti»); опечаток программа не угадывает.
Запись в оболочке занимает всё окно: **F2** — протокол поверх справа,
**Ctrl+Enter** — копирует и показывает запись и протокол рядом (Esc — убрать).
Протокол — холст: серые полосы — что ещё не написано, голубая — следующее;
своё пишите прямо в протоколе — оно сохраняется, удалённая строка не возвращается.

### Подсказки при наборе

С третьей буквы — серый «хвост» слова: **Tab** принимает. Несколько вариантов —
список: **↓/↑** и **Enter**/**Tab**. **Enter** без стрелки — новая строка,
**Ctrl+Enter** — сформировать, **Esc**, пробел, запятая — закрыть,
**Ctrl+Пробел** — показать раньше. Слова — из вашего словаря, ваших прошлых
записей и пунктов пресета. Флажок «Подсказки» — выключить.

Привычные фразы: начали фразу, которую уже писали не меньше двух раз, — серым
её продолжение; после запятой — ваша обычная следующая фраза. **→** / **Tab** —
всю, **Ctrl+→** — по слову.

Фразы со списками: **.имя** + **Tab** — фраза в записи; подсвеченные поля —
**↓/↑** выбрать, набрать своё, **Tab** — следующее, **Esc** — выйти. Программа
сама предлагает «сделать фразой» то, что вы часто пишете с разными числами;
фразы — в редакторе (вкладка «Фразы») и в xlsx (лист «Фразы»).

## Диагностика (сбор случаев, где программа ошиблась)

Галочка **«Диагностика»** вверху окна. Пока она включена, в шапке горит
«● Диагностика включена», и программа записывает в папку `diagnostics` рядом
с собой файлы `diag-ГГГГ-ММ-ДД.jsonl`:

- краткую запись врача и что программа из неё поняла;
- выданный протокол, предупреждения и значения по умолчанию;
- что врач скопировал после правок и **чем это отличается** от выданного;
- сохранённые эталоны и сбои.

Как собрать данные: включите галочку, работайте как обычно — **исправляйте протокол
в окне программы и копируйте кнопкой «Копировать»** (так правка попадёт в файл).

**«Ошибка → Исключить».** Лишняя строка в протоколе: выделите её, правая кнопка →
«Ошибка» → «Исключить». Строка убрана, случай (что и откуда) сохранён всегда, даже
без галочки; «Вернуть» — если промахнулись.

**«Отметить ошибку».** Исправьте протокол в окне так, как нужно, и нажмите
«Отметить ошибку» (после копирования исправленного протокола программа сама
предложит кнопку «Отметить, что пошло не так»). Выберите одно:

- **Я** — записал(а) неточно: опечатка, сокращение, забыл(а) что-то написать
  (можно поправить, как надо было записать);
- **Программа** — записал(а) правильно, а программа поняла не так;
- **Классификатор** — в списке нет нужного пункта;
- **Не знаю** — просто сохраните.

Случай сохраняется в папку диагностики всегда, даже если галочка выключена.
Кнопка **«Папка»** открывает папку с файлами — передайте их разработчику вместе
с выгруженным пресетом («Пресет» → «Экспорт xlsx…»). Записывайте только обезличенные данные (без ФИО).

### Телеметрия (на сервер, в реальном времени)

Если рядом с программой лежит `telemetry.json`, то при включённой
«Диагностике» те же события и действия врача (подсказки, кнопки, время на
запись) уходят на сервер клиники. ФИО вырезаются до отправки и ещё раз на
сервере. Без сети события ждут в папке `telemetry`. Состояние — в «О программе».
Установка сервера и раздача файла по компьютерам — [docs/telemetry.md](docs/telemetry.md).

## Пресеты

**Пресет** — логика одного типа карточки: пункты протокола, как выбирать варианты,
эталоны и слова врача. Пресетов может быть несколько
(«Активация», «Консультация»…); нужный выбирается кнопкой **«Пресет: …»**.

- **Импорт xlsx…** — создать новый пресет из файла или обновить текущий.
  Файл с ошибками не импортируется: программа покажет, что исправить, а прежний
  пресет останется рабочим. Если в пресете есть эталоны, которых нет в файле,
  программа предложит сначала выгрузить их.
- **Экспорт xlsx…** — выгрузить пресет в файл того же формата: его можно
  поправить в Excel, отправить разработчику или передать коллеге.
- **Смена пресета** не трогает запись. Если протокол не правили, он сразу
  пересобирается (в строке статуса — «Вернуть»); если правили — программа
  спросит, пересобрать ли. Буфер обмена при смене не меняется.

### Редактор пресета

**«Пресет: … ▾» → «Изменить пресет…»** или правый щелчок по строке протокола
→ «Изменить … в пресете». Слева — пункты деревом и поиск, справа — свойства
выбранного (текст, код, способ выбора, вариант по умолчанию, «всегда / если
упомянут», слова). Вкладки: **Эталоны** (✓/✗, «Принять новое как эталон»),
**Слова врача**, **Проверка** (одинаковые строки, перепутанный порядок
челюстей, пропуски номеров).

- Правки — черновиком: «Отменить» / «Вернуть» (Ctrl+Z / Ctrl+Y), «Отменить
  изменения», «Сохранить». Сверка эталонов идёт сама после каждой правки.
- Код ID_CLASS задаёт место пункта: раздел `4`, группа `4b`, вариант `4b7`.
  Смена кода переносит пункт; эталоны и слова врача переписываются сами.
  Занятый код соседа — программа предложит поменять местами.
- Excel по-прежнему — привычный способ объяснить пресет: «Экспорт xlsx…» /
  «Импорт xlsx…» есть и в редакторе.

### Логика пунктов (условия, «не вместе», сочетание)

- **Когда в протоколе:** всегда / если упомянут / **по условию**. Условие —
  строки «[пункт] = [вариант]» или «[пункт] упомянут», можно с «НЕ»,
  связка «все строки» или «любая строка».
- Условие считает только то, что есть в записи: не названный или
  подставленный по умолчанию пункт — «неизвестно», и строка не выводится.
- **Не вместе с** — пара пунктов; если в протоколе оба — оба с «проверьте».
- **Сочетание** у группы: «ИЛИ — один вариант» (по умолчанию) или «И — все
  упомянутые варианты».
- В xlsx — лист «Настройки», столбцы F «Сочетание» (`И`/`ИЛИ`), G «Условие»
  (`2b = 2b2 И НЕ 4p`, `4p упомянут`, скобки можно), H «Не вместе с» (коды
  через запятую).

## Файл пресета (xlsx)

Имя файла — любое. Первый лист, строка заголовка — та, где в колонке A написано
`ID_CLASS`.

| Колонка | Что | Пример |
|---|---|---|
| A `ID_CLASS` | код пункта | `4`, `4f`, `4f1` |
| B `CLASS_LIST` | текст пункта | `Назначены межчелюстные эластики` |
| C `ID_INPUT_RAW` | номер эталона | `1` |
| D `INPUT_RAW` | краткая запись эталона | `лигатурная, перепел…` |
| E `ID_CLASS_RESULT` | код строки идеального протокола | `4f1` |
| F `RESULT` | строка идеального протокола | `Перепел` |

Коды: `4` — раздел, `4f` — пункт (группа), `4f1`, `4f2`… — варианты группы.
Пункт без вариантов (например, `4a осмотр.`) попадает в протокол всегда.

**Добавить вариант** — новая строка в группе, например `4f7 | Слон`. Программа найдёт
его, если в записи есть это слово. Так же работают новые сроки явки (`5d5 | 3 недели.`),
жалобы, этапы.

**Добавить свою группу** — например, `4p | Эластическая цепочка без шага` с вариантами
`4p1 | на нижней челюсти.`, `4p2 | на верхней челюсти.`. Группа попадает в протокол,
только если о ней написано («цепочка на верхней»), а вариант берётся из той же фразы.
«Цепочка на обеих» даст оба варианта. Если вариант не понятен («тяга к минивинту» без
сегмента), в протокол попадёт строка группы, а оранжевым будет подсказка дописать.

**Добавить отдельный пункт** без вариантов (например,
`4o | Подвязывание зуба короткой металлической лигатурой.`). Пункт, которого нет
ни в одном эталоне, попадает в протокол, только если в записи есть его особое слово
(здесь — «короткой»). Пункты, которые есть в эталонах (осмотр, фотопротокол), идут всегда.

Если переименовали пункты в файле, сохраните эталоны заново: в старых эталонах остаются
прежние тексты, и сверка покажет расхождение.

**Пункт без вариантов** (`4a осмотр.`) идёт в протокол всегда, если он есть больше
чем в половине эталонов; иначе — только когда в записи есть его слово
(«Подвязывание зуба **короткой**…»).

**Эталоны** — пары «запись → идеальный протокол». При импорте, смене пресета и
запуске программа сверяет себя с ними: `✓ эталоны 3/3` — всё совпадает,
`⚠ эталоны 2/3` — где-то расхождение (кнопка «Подробнее» покажет, какие строки).
Кнопка **«Сохранить как эталон»** сохраняет текущую запись и исправленный протокол
в пресет; в xlsx эталон попадёт при экспорте.

Сверка идёт **по пунктам**, а не по тексту: переименовали пункт в файле — эталон
не ломается. Старые эталоны (где группа и вариант записаны одной строкой)
программа переводит сама. Строку, которую врач переписал своими словами, она
считает его формулировкой этого пункта, а совсем свою строку врача не проверяет;
сколько таких строк — видно в «Подробнее» («свои строки врача — N»).

**Лист «Настройки»** (необязательный; экспорт создаёт его сам) — как выбирать
вариант в группе: `Код | Способ выбора | Когда в протоколе | По умолчанию | Слова`.

- *Способ выбора* — например «по словам записи», «норма / не норма (гигиена)»,
  «срок (недели)», «названия (эластики)». Если не указан, программа угадает его
  по тексту группы, как раньше.
- *Когда в протоколе* (для пункта без вариантов) — «всегда» или «если упомянут».
- *По умолчанию* — код варианта, если врач ничего не написал (например `5d3` —
  явка через 6 недель).
- *Слова* — дополнительные слова, по которым программа узнаёт пункт, через запятую.

**Лист «Словарь»** — слова врача → пункт: `Слово | Пункт | Код | Добавлено |
Сработало раз`. Словарь у каждого пресета свой; он наполняется в программе
(«Если программа что-то пропустила») и выгружается при экспорте — его можно
поправить в Excel (удалить строку, исправить слово) и импортировать обратно.

## Сборка (для администратора)

Git не нужен: скачайте архив исходников
<https://github.com/minerdear0-jpg/Orthofill/archive/refs/heads/main.zip>,
распакуйте и в папке `Orthofill-main` выполните (нужен интернет — `uv` скачает
Python и библиотеки):

```
powershell -ExecutionPolicy Bypass -File build.ps1
```

Скрипт сам поставит `uv`, Python и библиотеки, прогонит тесты и соберёт:

- `dist\Orthofill-<версия>-portable.zip` — портативная версия (основная);
- `dist\Orthofill-<версия>.exe` — exe одним файлом.

Версия и код сборки видны в заголовке окна: «Orthofill 0.2 beta 3 · сборка 4c1de53 · 2026-10-21».
Код сборки — это коммит git, из которого собрана программа (в архиве GitHub его
подставляет сам GitHub в `orthofill/_commit.txt`).

Разработка: `uv run pytest` — тесты, `uv run python -m orthofill` — запуск,
`uv run python -m orthofill --test order.xlsx` — сверка с эталонами в консоли.
